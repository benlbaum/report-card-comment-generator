    Help

    Saving your work

    • Local storage: student details, comments, choices, and values save automatically in this browser, including after closing it or shutting down.
    • Returning: use the same site, browser, profile, and device. No import is needed each visit; devices do not sync.
    • Phrase-bank edits: choose Save bank before leaving. Discard changes cancels pending edits.
    • Keep a backup: private windows or clearing browser data can erase work. Export a class backup for a safety copy or to move devices.

    Importing and exporting

    • Class backup (JSON): all students, comments, choices, values, and the saved phrase bank—not the website. Import class backup replaces the current class after confirmation; Undo is available.
    • Comments (CSV): final comments for a spreadsheet or report cards. This file cannot restore your class.
    • Roster: share student names and pronouns. Comments, values, and phrases are excluded. Import can add students or start a class from the list.
    • Phrase bank: share phrases, settings, and order—no students or comments. Import can add new topics or replace the bank; choose Save bank to apply it.
    • Files are copies: editing an exported file does not update the site. Import the changed file in its matching section.

    Writing comments

    • Student and Topic: choose each dropdown or use Previous/Next. Pick a phrase; Skip this topic leaves it out.
    • Live draft: builds from your choices. Use draft copies it to the final comment, where you can edit freely.
    • Value Entry: enter a value and pick its matching phrase. Units are added automatically; blank skips the topic, and zero is valid.
    • Final comment: copy it or choose Mark done & next. The counter warns above 1,000 characters but lets you keep editing.

    Class and phrase tools

    • Student roster: add, edit, remove, or sort students. Start a new class replaces students and comments while keeping the phrase bank.
    • Class overview: review and filter comments, copy each student's text, or choose a topic to edit across the class.
    • Phrase bank: edit topics, Selection options, or Value Entry phrases. Drag handles to reorder; focused handles also use Up/Down keys.
    • Load default bank: previews the starter phrases before replacing anything. Save bank applies the change.
